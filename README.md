# Bolão Copa 2026 · Valencia / Legion / PPK

Pacote público para GitHub Pages, sem área administrativa e sem e-mails.

## Publicação

Envie o conteúdo desta pasta para o repositório público do GitHub Pages. O arquivo `index.html` precisa ficar na raiz.

## Atualização de resultados

Use o pacote administrativo local privado para gerar o novo `data/resultados.json` e substitua apenas esse arquivo no GitHub.

## Segurança

Este pacote não contém `admin.html`, `admin.js` nem auditoria privada. Tudo aqui é somente leitura.

## Aparência

Interface reorganizada para se aproximar da experiência visual do app Base44: navegação lateral no desktop, navegação inferior no mobile, cards arredondados, paleta azul/verde/dourado, páginas Home, Ranking, Palpites, Jogos, Estatísticas, Comparar, Simulador e Regras.
